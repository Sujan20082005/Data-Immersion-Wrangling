# Data Dictionary

| Column Name | Data Type | Description |
|-------------|-----------|-------------|
| Order_ID | Object | Unique identifier for each order |
| Order_Date | Date | Date when the order was placed |
| Customer_ID | Object | Unique identifier for each customer |
| Customer_Name | Object | Name of the customer |
| Age | Integer | Age of the customer |
| Gender | Object | Gender of the customer |
| City | Object | Customer's city |
| Product | Object | Purchased product |
| Category | Object | Product category |
| Quantity | Integer | Number of units purchased |
| Unit_Price | Float | Price of one unit |
| Total_Sales | Float | Total amount of the order |
