# ApexPlanet Data Analytics Internship - Task 1

## Data Immersion & Wrangling

### Project Overview
This project was completed as part of the ApexPlanet Data Analytics Internship. The objective was to understand the dataset, assess its quality, clean and transform the data, and prepare it for further analysis using Python and Pandas.

## Dataset
- Dataset: ApexPlanet_DataAnalytics_Dataset.xlsx
- Records: 1000
- Columns: 12

## Tools Used
- Python
- Pandas
- Google Colab
- Microsoft Excel

## Data Quality Assessment
The following checks were performed:
- Checked missing values
- Checked duplicate records
- Verified data types
- Standardized text formatting
- Converted date format
- Checked invalid values
- Verified Total Sales calculations
- Detected outliers using the IQR method

## Data Cleaning Performed
- Removed duplicate records
- Filled missing values
- Standardized text columns
- Converted the Order_Date column to datetime format
- Verified Total_Sales values
- Exported the cleaned dataset

The dataset was successfully cleaned and prepared for future data analysis.
